# 自己検閲(ツールなし環境向け)

`node scripts/check.mjs` が使えない環境(Claude.ai 等)での、機械検証の代用手順。
**この手順は本物の常用漢字一覧と同等の厳密さは持たない**。候補字の約9割を機械的に除外する速く正確な一次検査として使い、確信が持てない字は `references/joyo-2136.md`(全2136字)を照合する。

## 手順

1. 出力文を**視覚走査**で一気に1次除外する。以下は即座に違反:
   - かな(ひらがな・カタカナ)1字でもあれば違反。文脈が通るかではなく、**文字種だけ**を見る
   - 英字・アラビア数字・約物(、。「」()…等)・空白は違反
   - 字体が複雑すぎる漢字・見覚えのない漢字は要確認
2. 見覚えのない字・漢語らしく見える字を拾い、下の置換表と照合する。表にあれば置換
3. 置換表にない不審字は `references/joyo-2136.md` の該当ブロックを照合する。掲載がなければ表外字=違反
4. 熟語単位で疑う。「疲労困憊」「代碼」「此処」のように見える熟語に表外字が隠れる。1字単位で分解して照合する
5. 合格後も、かなと記号の混入だけは送信直前に再確認する(視覚走査は見落としにくいが、見落としたら即違反になる)
